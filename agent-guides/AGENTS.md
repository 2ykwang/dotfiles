# 작업별 가이드

아래 인덱스를 먼저 읽고, 요청에 해당하는 상세 가이드를 읽는다. 현재 컨텍스트에서 이미 읽은 동일 내용은 다시 읽지 않는다.

| 상황                                                                                             | 읽을 문서            |
| ------------------------------------------------------------------------------------------------ | -------------------- |
| 코드를 작성, 수정, 리팩터링, 테스트하거나 리뷰하는 경우                                          | [code.md](code.md)   |
| 사용자가 Herdr의 기능 조사, 터미널 조작, 에이전트 협업, 원격 연결, 설정이나 자동화를 요청한 경우 | [herdr.md](herdr.md) |

- 일반 터미널 실행이나 병렬 작업이 유용하다는 이유만으로 Herdr를 사용하지 않는다.

## 가이드 피드백

- 가이드를 실제로 사용하면서 오류, 작업이나 결과에 영향을 주는 누락, 검증된 개선 방법을 발견하면 근거와 개선안을 짧게 보고한다.
- 이 디렉터리에는 반복 적용할 고정 지침만 둔다. 일회성 조사, 실험 기록과 측정 데이터는 저장하지 않는다.
