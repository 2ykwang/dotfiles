# 작업별 가이드

해당하는 문서만 읽는다. 이미 읽은 문서는 다시 읽지 않는다.

| 상황                                    | 문서                 |
| --------------------------------------- | -------------------- |
| 코드 작성, 수정, 리팩터링, 테스트, 리뷰 | [code.md](code.md)   |
| 사용자가 Herdr 사용이나 조사를 요청     | [herdr.md](herdr.md) |

- 병렬 작업이나 터미널 실행이 유용하다는 이유만으로 Herdr를 쓰지 않는다.
- 가이드의 오류나 결과에 영향을 준 누락을 발견하면 근거와 개선안을 짧게 보고한다.
- 이 디렉터리에는 반복 적용할 고정 지침만 둔다. 조사와 실험 기록은 두지 않는다.
- 지침은 단언형 한두 줄로 쓴다. 경위와 배경 설명은 쓰지 않는다.
